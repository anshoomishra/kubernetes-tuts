# Shared Scripts

Place optional, reviewable automation here, such as manifest validation, lab setup, and cleanup helpers.

Before running a script:

- Read the full script and inspect its target context/namespace.
- Prefer dry-run or confirmation options for destructive operations.
- Never embed credentials or personal kubeconfig data.
- Keep scripts portable and document prerequisites and cleanup.

The module labs can also be followed manually; scripts are not required to learn Kubernetes.
